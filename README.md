# Orbit - AI Virtual Assistant

A voice-controlled AI Virtual Assistant built with HTML, CSS, and JavaScript. Orbit can understand voice commands, respond with speech, and perform basic tasks like opening websites, telling time/date, and answering greetings.

## ✨ Features

- **Voice Recognition**: Uses Web Speech API to convert speech to text
- **Text-to-Speech**: Responds back to the user using SpeechSynthesis
- **Time-based Greeting**: Greets "Good Morning / Afternoon / Evening" on load
- **Command Execution**: 
    - Open websites: YouTube, Google, Spotify, Pinterest, WhatsApp
    - Open system apps: Calculator
    - Tell current **Time** and **Date**
    - Answer basic questions: "who are you", "hello", "what's my name"
- **Google Search**: Searches the web for any query it doesn't recognize
- **Responsive UI**: Clean, dark-themed interface with animated voice indicator

## 🛠️ Tech Stack

- **Frontend**: HTML5
- **Styling**: CSS3 + Google Fonts
- **Logic**: Vanilla JavaScript
- **APIs Used**: 
    - `SpeechRecognition` / `webkitSpeechRecognition`

## ✨ Key Features

- **Voice Recognition**: Converts speech to text using `SpeechRecognition API`
- **Text-to-Speech**: Speaks responses using `SpeechSynthesis API`
- **Smart Greetings**: "Good Morning / Afternoon / Evening" based on time
- **App & Website Launcher**: 
  `Open YouTube`, `Open Google`, `Open Spotify`, `Open WhatsApp`, `Open Calculator`
- **Utility Commands**: 
  `What is the time`, `What is the date`, `Who are you`, `Hello`
- **Fallback Search**: Auto-searches on Google if command not recognized
- **Visual Feedback**: Animated GIF shows when assistant is listening
